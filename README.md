## How I approach a problem

1. Define the decision and the metric denominator.
2. Check data grain, coverage and reconciliation.
3. Connect cost with quality and customer outcomes.
4. Turn findings into a controlled experiment with explicit stop rules.
5. Make the evidence understandable to the people who implement the change.

**Tools:** SQL · BigQuery · Python/Pandas · Google Sheets · Git · LLM workflows
